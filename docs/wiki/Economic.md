# Economic

## How the project creates value

The product is an internal engineering tool for the partner, not a product sold to the public. Its measurable impact is engineering time: preparing manufacturing data for analysis is repeated manual work, and each pipeline built once in the tool can be rerun, reviewed and reused.

No savings have been measured. Claiming a number now would be invention.

## What we will measure

| Outcome | Measurement |
|---|---|
| Time to prepare a dataset | Same task done by hand and with the tool, by the same role, including set-up and corrections |
| Reuse | Number of runs per saved pipeline; pipelines reopened and modified instead of rebuilt |
| Defects caught before analysis | Rows stopped by data-quality blocks on a reviewed reference dataset |
| Reproducibility | Reruns of a saved revision that produce the same output |

Each measurement records the participant's role, dataset size and limits. Time is converted to money only with an hourly rate the partner supplies.

## If it were commercialized

The realistic model is a per-seat internal licence or a services engagement to build connectors for a site's source systems. Costs to weigh against it are maintenance of connectors as source systems change, training, and support. We have not priced these.
