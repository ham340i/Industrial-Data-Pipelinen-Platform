# Meeting minutes

## Recorded meetings

No minutes were taken at the team's meetings during Release 1. Team coordination is visible in issue and pull-request discussion, for example the review threads on [#74](https://github.com/ham340i/Industrial-Data-Pipelinen-Platform/pull/74), [#72](https://github.com/ham340i/Industrial-Data-Pipelinen-Platform/pull/72) and [#59](https://github.com/ham340i/Industrial-Data-Pipelinen-Platform/pull/59).

The [Release 1 team activity log](https://github.com/ham340i/Industrial-Data-Pipelinen-Platform/blob/main/docs/meetings/team-activity-log-release-1.md) lists, for every Monday and Wednesday from October 5 to November 17, 2026, the pull requests merged, reviews submitted and issues opened or closed since the previous entry. It was reconstructed from GitHub history after the release and is not a record of what was said in meetings.

From Iteration 5, each meeting is recorded here by its note taker, in the format below.

## Format for each meeting

```text
<Date>
Attendance: <GitHub usernames>
Absent: <GitHub usernames>
Note taker: <rotates each meeting>
Notes:
- <decision or discussion point>
Action items:
- <owner>: <action>, linked to an issue
```

Use GitHub usernames, not student IDs or contact details. Summarize confidential stakeholder discussion without publishing private data. The same template is kept in the repository as [docs/meetings/TEMPLATE.md](https://github.com/ham340i/Industrial-Data-Pipelinen-Platform/blob/main/docs/meetings/TEMPLATE.md).
