# Industrial Data Pipeline Engineering Platform Wiki

Industrial Data Pipeline Engineering Platform is a SOEN 490 capstone project for a local-first visual ETL platform that integrates approved manufacturing data sources with analytics and ML workflows.

**Industry partner:** Pratt & Whitney Canada.

**Status:** repository foundation and planning. No application, completed iteration, release or stakeholder approval is claimed. The documentation in the main repository is authoritative; this Wiki provides navigation to it.
