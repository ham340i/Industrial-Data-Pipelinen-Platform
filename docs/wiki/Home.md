# Local Pipeline Studio Wiki

Local Pipeline Studio is a SOEN 490 capstone project for a local-first visual ETL platform that integrates approved manufacturing data sources with analytics and ML workflows.

**Status:** repository foundation and planning. No application, completed iteration, release or stakeholder approval is claimed. The documentation in the main repository is authoritative; this Wiki provides navigation to it.
